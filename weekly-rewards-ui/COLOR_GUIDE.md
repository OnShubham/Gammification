## Color Usage Summary

### Most Used Colors
1. **#5DADE2** - Primary blue (header, cards, hoodie)
2. **#FFFFFF** - White (text, backgrounds, highlights)
3. **#FFD700** - Gold (coins, stars)
4. **#FF6B9D** - Pink (ribbon, decorations)
5. **#FFD93D** - Yellow (gift box)

### Accent Colors
- **#3498DB** - Button gradient end
- **#85C1E9** - Light blue (header gradient, title)
- **#FDB813** - Golden yellow (coin details)

### Neutral Colors
- **#F0F0F0** - Very light gray (mascot head)
- **#E8E8E8** - Light gray (hands, headphones)
- **#2C3E50** - Dark blue-gray (eyes, details)

## Hex to RGB Conversions

For use with rgba():

- `#5DADE2` = `rgb(93, 173, 226)`
- `#85C1E9` = `rgb(133, 193, 233)`
- `#3498DB` = `rgb(52, 152, 219)`
- `#FFD700` = `rgb(255, 215, 0)`
- `#FDB813` = `rgb(253, 184, 19)`
- `#FF6B9D` = `rgb(255, 107, 157)`
- `#FF8FB3` = `rgb(255, 143, 179)`
- `#FFD93D` = `rgb(255, 217, 61)`
- `#A63B1F` = `rgb(166, 59, 31)`
- `#8B2F15` = `rgb(139, 47, 21)`

## Color Accessibility

### Contrast Ratios (WCAG AA)

- White text on #5DADE2: ✅ Pass (3.2:1)
- White text on #3498DB: ✅ Pass (3.5:1)
- #85C1E9 text on white: ✅ Pass (2.8:1)
- White text on #A63B1F: ✅ Pass (5.8:1)

All text colors meet WCAG AA standards for their backgrounds.
